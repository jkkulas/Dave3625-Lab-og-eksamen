Handling inconsistencies in course examples

Some slide footer numbers differ from the slide position; references use the actual slide position. A numeric stock price is regression, while up/down direction is classification. Regression association alone does not prove causation. Residuals do not always sum to zero, particularly on held-out data; signed errors can cancel. Naive Bayes assumes conditional independence given a class. A Gaussian mixture is limited by its component shapes, not an arbitrary-shape guarantee. A missing cabin record does not prove no cabin existed.

Some practical walkthroughs scale before splitting or suggest using a final grade that defines a target. The practice answers follow the later leakage guidance: fit learned transformations within training folds, and use only features available at the intended prediction time. SUPPLEMENTARY · NEURAL NETWORKS

From inputs to an update

A basic neuron computes a weighted sum plus a bias, then applies an activation. Weights and biases are learned parameters. Layer counts, learning rate and a chosen training budget are hyperparameters. A hidden layer is an intermediate representation between input and output.

z = w₁x₁ + … + wₙxₙ + b
a = activation(z)

Nonlinear activations allow networks to express nonlinear functions. Without them, a sequence of affine layers collapses to one affine transformation. ReLU computes max(0, z). Sigmoid maps a real score to (0, 1), often for a binary output. Softmax normalises several class scores into nonnegative values summing to one. Neither sigmoid nor softmax guarantees correctness or calibration. A linear numeric output is a common choice for unconstrained regression.

The forward pass computes predictions with current parameters. A loss compares predictions with the objective. Backpropagation uses the chain rule to compute derivatives through the network. An optimiser then uses those gradients to update parameters. Backpropagation itself is not a promise of a global optimum.

gradient descent: w_new = w − learning_rate × gradient

A positive gradient leads to a downward parameter update; a negative gradient leads to an upward update. Too large a learning rate can overshoot or destabilise training; too small a rate can make progress slow. Input scaling can improve conditioning. Symmetry-breaking initialisation helps hidden units learn different functions.

A mini-batch is a subset used for an update. An epoch is one pass through the training set. More epochs or parameters do not guarantee better unseen-data performance. Falling training loss with rising validation loss can indicate overfitting. Regularisation limits fit to training-specific details; dropout randomly omits selected activations during training. Validation-guided early stopping chooses a stopping point without consulting the final test.

Ng's chapter 4 (PDF pages 10–11) explains the role of suitable data and computation in scaling networks and cautions that small datasets do not guarantee an advantage over simpler methods.

SUPPLEMENTARY · GENERATIVE AI & PROMPTING

Generation is not verification

Generative systems produce content such as text, images, audio or code. A language model operates on tokens: encoded text units that may be words, subwords or other fragments. Next-token training estimates which token is likely given preceding context. Learning statistical regularities is not the same as checking every factual assertion against reality.

Pretraining learns broad patterns from an initial corpus. Fine-tuning updates parameters with additional training. Prompting supplies instructions and context at inference time; it does not by itself imply permanent weight updates. Zero-shot prompts contain no task demonstrations; few-shot prompts provide a small number of examples. Foundation models can be reused across tasks but need application-specific evaluation.

A clear prompt specifies the task, relevant context, intended audience, constraints and expected output. A schema makes required fields explicit; it does not ensure their values are true. The context window is bounded, so a model cannot necessarily use every part of a large document or retain an entire interaction indefinitely.

Retrieval-augmented generation supplies relevant retrieved documents to the model as context. It is distinct from updating weights. Retrieval can miss relevant evidence or return unsuitable material; generation can misinterpret or invent claims. Check whether citations exist, whether they support the statements and whether the source is appropriate. State an evidence gap when supplied material does not support an answer.

Sampling temperature changes how concentrated the token distribution is. Higher temperature generally increases variability. Lower temperature does not guarantee truth: a model can confidently and repeatedly produce the same wrong answer. Fluent unsupported claims, including fabricated citations, are often called hallucinations.

Compare prompts using the same representative tasks and a clear rubric. Include difficult and varied cases, measure factual support and task success separately from fluency, and retain held-out examples because prompt selection can overfit. Generated code needs relevant inspection and tests rather than reliance on a claim that it works.

Prompt injection occurs when untrusted content, such as a retrieved document, tries to redirect instructions. Treat such text as data rather than authority. Tool-using agents can act on files or services, so evaluate task success, failure modes and action boundaries. Human decisions about permissions should reflect the intended workflow. Multimodal systems process or generate more than one modality; this does not imply equal reliability in every modality.

SUPPLEMENTARY · RESPONSIBLE AI

Judge the system in its use setting

Overall accuracy can hide different error rates across groups. Investigate representation, label definitions, subgroup outcomes and error costs. Removing a protected attribute does not guarantee fairness because other features can serve as proxies and labels can encode historical decisions. An interpretable rule can still be unfair; explanation supports inspection but is not an ethical conclusion.

Collect information for a defined task and consider whether less identifying data can suffice. Replacing names with keys is pseudonymisation, not a guarantee of irreversible anonymisation. Remaining attributes may enable re-identification, and trained models can memorise information. These are conceptual study points, not a legal determination about a particular system.

Accountability means people and organisations have clear responsibility for decisions, monitoring and correction. Effective oversight gives reviewers relevant evidence, enough time and authority to challenge an output. Automation bias is the tendency to defer too readily to an automated suggestion, even when contrary evidence exists.

Document dataset provenance, assumptions, limitations and intended uses. Monitor after deployment because data and use conditions can change. Evaluate consequences for access to services, work and the distribution of errors, alongside model quality. A small showcase or high benchmark score may not represent the intended users, languages or constraints. Describe claims in terms of specific tasks, datasets, metrics and limitations; this bank makes no claim about the latest model rankings.

SUPPLEMENTARY · CLUSTERING

Different definitions of a group

K-means alternates nearest-centre assignment and mean updates. It minimises within-cluster squared Euclidean distances and typically favours compact groups. Initialisation can affect its local solution. Means are outlier-sensitive; feature scaling matters. Increasing K can improve compactness without proving a more useful segmentation. Cluster IDs are arbitrary identifiers, not ranks.

DBSCAN connects dense neighbourhoods determined by a radius and minimum count, and can mark sparse observations as noise. It can find irregular shapes but depends on density settings and scale. Mean shift moves local windows towards density peaks; bandwidth influences the resulting groups.

Gaussian mixture models represent a distribution with Gaussian components and can give soft membership probabilities. Components may be elliptical depending on their covariance model; they do not guarantee arbitrary shapes. Agglomerative hierarchical clustering begins with small groups, often single points, and merges them into a hierarchy. A dendrogram depicts merge levels; cutting it at different heights produces different partitions.

Association-rule mining instead examines co-occurring items. Apriori finds frequent itemsets as a basis for rules. A shopping-basket association is not proof that purchasing one item causes another purchase.

SUPPLEMENTARY · CLASSIFIERS

Kernel and likelihood choices

A linear SVM has a linear boundary in its input feature space. An RBF kernel allows nonlinear boundaries in the original space. More flexibility is not always better: evaluate kernel choices with a consistent validation procedure, scaling within training folds. The final test must remain independent of selection.

Naive Bayes combines class priors with feature likelihoods under conditional independence given class. Gaussian Naive Bayes models numeric features with Gaussian class-conditional distributions; it does not require identical means for every class. These assumptions are approximations that must be assessed in the intended application.

SUPPLEMENTARY · PROBABILISTIC METRICS

Probabilities and decisions

Binary log loss penalises confident wrong probabilities strongly: for a positive observation the contribution is −log(p), and for a negative observation it is −log(1−p). Lower is better. ROC curves plot true-positive rate against false-positive rate as a threshold changes. ROC-AUC summarises ranking/separation across thresholds; it does not guarantee calibration or good precision at a chosen operating threshold. Thresholded precision and recall must be checked for the task and class balance.
